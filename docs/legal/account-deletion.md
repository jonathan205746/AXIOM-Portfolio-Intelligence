# AXIOM Portfolio Intelligence — Account Deletion

## In-App Deletion (Recommended)
1. Open App → Settings → Delete Account
2. Enter password + confirm "DELETE"
3. Account & all data permanently removed

## Web Deletion (Alternative)
If you cannot access the app:
1. Visit: https://axiom.example.com/account-deletion
2. Enter username + email
3. Receive deletion code via email
4. Confirm deletion

## What Gets Deleted
- Account credentials (username, email, password hash)
- All portfolios and holdings
- Analysis history and results
- Authentication tokens (access + refresh)
- API request logs (retained 180 days per CERT-In, then auto-deleted)

## Data Retention After Deletion
| Data | Retention | Reason |
|------|-----------|--------|
| Anonymized analytics | Indefinite | Product improvement (no PII) |
| Audit logs | 180 days | CERT-In compliance |
| Backup snapshots | 30 days | Disaster recovery |
